## Ключевая формулировка урока

**Node.js — хост для V8: V8 исполняет JavaScript и управляет кучей, libuv даёт event loop, неблокирующий сетевой ввод-вывод и пул потоков для блокирующих операций, C++ bindings связывают их с JavaScript API. Однопоточен только JavaScript на одном event loop, процесс — многопоточный. Скорость JavaScript — результат спекуляции: интерпретатор собирает обратную связь о формах объектов и типах, оптимизирующие компиляторы делают на неё ставку и откатываются при нарушении. Для backend из этого следуют стабильные формы данных и валидация на границе; остальное — только по профилю.**

## Как проверялись примеры

Каждый пример с выводом запущен на **Node.js v22.22.2** (V8 12.4.254.21, libuv 1.51.0, Windows 10 x64) как файл `.cjs`; примеры с `%`-функциями — с флагом `--allow-natives-syntax`. Версионные утверждения (Maglev, dictionary mode после `delete`, Smi) повторены на **v24.22.0** и **v26.12.0**. Число потоков измерено на Windows 10 и в Docker на образе `node:22.22.2-slim` (Linux) и зависит от ОС. Время в эксперименте с inline caches — один запуск, при повторах отличалось на 10–25 %, вывод опирается на форму кривой, а не на числа. Состояние Maglev сверено с CHANGELOG_V22 и `configure.py`, значения по умолчанию — с исходниками Node.js v22.22.2 и `--v8-options`, поведение API — с документацией Node.js latest-v22.x и libuv v1.x, механизмы V8 — с блогом и документацией v8.dev.
