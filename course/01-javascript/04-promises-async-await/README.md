## Цель

1. Когда начинается работа, что выполнится синхронно и что будет отложено.
2. Кто поймает ошибку, а какая станет необработанной и уронит процесс.
3. Что продолжит работать после ошибки, таймаута или ответа клиенту, и как это остановить.

## Ключевая формулировка урока

**Promise — это результат, который появится позже, а не поток и не задача. `await` приостанавливает только свою функцию и не блокирует поток; работа начинается при вызове, а не при `await`. Ни Promise, ни комбинаторы ничего не отменяют: отмена — протокол `AbortSignal`, который нужно передать до каждой операции. Отклонение без обработчика к моменту проверки Node.js завершает процесс.**

## Как проверялись примеры

Каждый пример с выводом запущен на **Node.js v22.22.2** как файл `.cjs`. Примеры с таймерами используют широко разнесённые задержки и перепроверены несколькими запусками: таймеры с близкими сроками на Windows срабатывали в разном порядке. Вывод TypeScript для `async` / `await` получен компилятором **TypeScript 7.0.2** с `--target es2015`. Поведение Node.js сверено с документацией latest-v22.x и исходником `lib/internal/process/task_queues.js` тега v22.22.2. Тексты сообщений об ошибках — формулировки V8 и Node.js.
