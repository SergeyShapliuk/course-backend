## Ключевая формулировка урока

**Итерация, приведение типов, числа и слабые ссылки — протоколы с точными правилами. Ресурс итератора закрывается через `return()`, только если потребитель вышел корректно. Number — двоичная плавающая точка с точными целыми до 2⁵³ − 1, поэтому деньги и большие идентификаторы требуют другого представления. JSON на границе теряет типы молча. Спецификация не гарантирует сборку мусора, поэтому ресурсы освобождают явно.**
