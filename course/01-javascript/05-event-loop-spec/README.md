## Ключевая формулировка урока

**ECMAScript не определяет event loop: он определяет jobs, требует выполнять их на пустом стеке до конца и выполнять promise jobs в порядке постановки. Цикл, таймеры, ввод-вывод и очередь микрозадач — часть хоста. Пока очередь микрозадач не пуста, хост не обрабатывает ни таймеры, ни сеть, а `await` уступает только другим микрозадачам.**

## Как проверялись примеры

Каждый пример с выводом запущен на **Node.js v22.22.2** как файл `.cjs` и повторён несколько раз; примеры, порядок которых зависит от взаимного расположения таймеров и `setImmediate` в главном модуле, в урок не включены (этот порядок не гарантирован, 3.2). История изменений сверена по текстам редакций ECMAScript 2015, 2018, 2019, 2020 на 262.ecma-international.org; модель хоста — по стандарту HTML и исходнику `lib/internal/process/task_queues.js` Node.js v22.22.2.
