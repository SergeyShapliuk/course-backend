## Ключевая формулировка урока

**Замыкание — функция вместе с окружением, в котором она создана; хранится связывание, а не значение. Что физически остаётся в памяти, решает движок: V8 держит захваченные переменные в одном контексте на scope, общем для всех замыканий scope. Утечку создаёт не замыкание, а долгоживущий объект, который его держит.**

## Как проверялись примеры

Каждый пример с выводом запущен на **Node.js v22.22.2** (V8 12.4.254.21-node.39) как файл `.cjs`. Примеры про сборку мусора запускались с `--expose-gc` и проверяют удержание через `WeakRef` после выхода из текущей задачи. Это поведение конкретной версии V8, а не гарантия ECMAScript. Цепочки retainers получены из `v8.writeHeapSnapshot()` программным разбором снимка. Тексты предупреждений и ошибок — формулировки Node.js и V8.
