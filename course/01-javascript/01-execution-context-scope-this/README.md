## Цель

По любому фрагменту кода уметь ответить на три вопроса и объяснить ответ через механизм языка:

1. Какое значение увидит каждая ссылка на имя и почему именно это.
2. Что произойдёт при обращении к имени до объявления: `undefined`, `ReferenceError` или `TypeError`.
3. Чему равен `this` в конкретном вызове и почему он «теряется».

## Ключевая формулировка урока

**Call stack отвечает на вопрос «кто меня вызвал», scope chain — «где искать это имя», `this` — «как меня вызвали». Это три независимых механизма: стек строится в рантайме, цепочка окружений фиксируется местом объявления функции, `this` обычной функции определяется формой вызова.**
